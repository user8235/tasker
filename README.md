# Tasker

Tasker — веб-сервер для управления задачами, трекер задач.

## Структура проекта

tasker/                     
├── api/                            # api
│   ├── auth.go                     # функции для авторизации (в перспективе)
│   └── handlers.go                 # основные обработчики для операций с задачами
├── cmd/                            # исполняемые файлы проекта
│   └── tasker/     
│       └── main.go                 # основной файл
├── models/                         # описание структур
│   └── task.go                       
├── storage/                        # функции для работы с БД
│   └── sqlite.go                   # функции для работы с БД
├── utils/                          # дополнительные функции
│   └── date.go                     # функции для работы с датами
├── web/                            # содержит файлы фронтенда
├── tests/                          # тесты для проверки API
├── dockerfile                      # Dockerfile для сборки контейнера
├── docker-compose.yml              # Файл конфигурации Docker Compose
├── go.mod
└── go.sum


## Инструкция по установке и запуску
Требования
- Установленный Docker
- Установленный Docker Compose

1. Клонирование репозитория
Клонируйте репозиторий с проектом:
```
git clone https://github.com/user8235/tasker.git
```
и перейдите в директорию с проекта:
```
cd tasker
```
2. Запуск проекта с помощью Docker Compose
В корневой директории проекта выполните команду:
```
docker-compose up
```
Эта команда:
Соберёт Docker-образ для вашего приложения.
Запустит контейнер с вашим приложением.

После успешного запуска приложение будет доступно по адресу:
http://localhost:7540

3. Остановка проекта
Чтобы остановить контейнеры, выполните команду:
```
docker-compose down
```

4. Использование переменных окружения
Если вам нужно изменить настройки приложения (например, порт или путь к базе данных), вы можете передать переменные окружения через docker-compose.yml или через командную строку.

Пример изменения порта:
```
docker-compose up -e TODO_PORT=8080
```

5. Просмотр логов
Чтобы просмотреть логи работы приложения, выполните:
```
docker-compose logs -f
```
6. Запуск в фоновом режиме
Чтобы запустить контейнеры в фоновом режиме, используйте флаг -d:
```
docker-compose up -d
```
7. Очистка Docker
Если вы хотите удалить все контейнеры, образы и тома, связанные с проектом, выполните:
```
docker-compose down --rmi all --volumes
```
